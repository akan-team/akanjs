Every HTML response now sends `Content-Security-Policy-Report-Only` with a `script-src` that names each script the framework writes, so the browser reports any other inline script a page runs. 3.5.0 will enforce the same policy.

- A server-rendered page sends `script-src 'self' 'nonce-…' 'sha256-…' 'strict-dynamic'`: the hashes name the document's bootstrap script, its flush call and the build's import map, and the nonce the scripts React writes to reveal a streamed boundary. A page replayed from the HTML cache carries no nonce and lists the hash of each of those scripts instead; a response names at most 32 hashes, which keeps the header under 2 KB (a proxy in front reads a response's headers into one buffer, 4 KB in nginx unless configured), so a page whose replay would need more is rendered each time, answers `X-Akan-Cache: BYPASS` with `X-Akan-Cache-Reason: script-hashes`, counts under that reason in `akan_route_cache_lookups_total` and is warned about once per route. `akan start` adds `'unsafe-eval'` and runs its dev scripts under the nonce.
- The document's per-request values (route state, dictionary URL, import map key, API and WebSocket prefixes) and its Flight chunks are now `<script type="application/json">` blocks that the static bootstrap script reads, where they used to be script text. The bootstrap script is the first element of `<head>`, and the client entry module is added by that script once the document ends, where it used to be a `<script type="module">` tag.
- The CSR document, the system pages, Akan Studio, the gateway's status page and the OAuth error page send the header too, each naming its own script by hash. The OAuth error page now also carries the headers every other HTML page has (`Content-Security-Policy: frame-ancestors 'self'; base-uri 'self'`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`).
- `scriptHashes("sha256-…")` and `scriptNonce()` from `akanjs/client` let a `.head()` name its own inline script: by hash for a constant snippet, which keeps the page cacheable, or by the response's nonce, which makes the page dynamic. Hashes a page declares past the 32 a response names are left out, with one warning per route.
- `AKAN_CONTENT_SECURITY_POLICY_SCRIPT_SRC` adds source expressions to every response's `script-src`, such as `'wasm-unsafe-eval'` for a page that compiles WebAssembly or the hash of a snippet every page carries.
- `AKAN_CONTENT_SECURITY_POLICY_REPORT_ONLY=off` drops the header, and any other value is sent in its place as written. `AKAN_CONTENT_SECURITY_POLICY_REPORT_URI` adds `report-uri` and `report-to` with a `Reporting-Endpoints` header. `AKAN_CONTENT_SECURITY_POLICY` works as before and does not change the report-only header.

**Upgrading.** The header only reports in 3.4; what changes for a page is its source and when `load` fires, both below. Load your pages with the browser console open. For each `[Report Only]` line about an inline script of your own, either call `scriptHashes()` in that page's or layout's `.head()` with the hash the line prints, or pass `nonce={scriptNonce()}` to the `<script>`; a `<script src>` written in JSX needs the nonce. Move an `onclick="…"` attribute or a `javascript:` URL into a component's handler. A page that compiles WebAssembly is reported as `wasm-eval`: set `AKAN_CONTENT_SECURITY_POLICY_SCRIPT_SRC="'wasm-unsafe-eval'"`. In the page source, the route state, the dictionary URL and each Flight chunk are now `<script type="application/json">` blocks, and the markup has no `<script type="module">` tag for the client entry: code or a test that read `self.__RSC_PUSH__(…)` text or looked for that tag finds neither. Because the bootstrap script adds the entry module, `DOMContentLoaded` and `load` no longer wait for it and can fire before any client code runs (on a cached docs page, `load` at 31 ms and the entry at 63 ms). A `load` or `DOMContentLoaded` listener that client code adds without checking `document.readyState` may never be called:

```ts
if (document.readyState === "complete") onLoad();
else window.addEventListener("load", onLoad, { once: true });
```

(`document.readyState !== "loading"` for `DOMContentLoaded`.) A browser test that clicks or types as soon as navigation reports `load` can meet a page that has not hydrated: wait for something only the hydrated page does, such as the result of the action under a retrying assertion or a marker a client component sets in an effect, instead of `load`. If a proxy or CDN in front of the app sets its own `Content-Security-Policy-Report-Only`, set `AKAN_CONTENT_SECURITY_POLICY_REPORT_ONLY=off` or let the app's header through.
