`akan preview` opens `/openapi.json` as written, as the server mounts it outside `/:lang`; before, it got the default locale and opened a 404 page. A full URL (`http://localhost:<port>/oauth/token`) now opens its path exactly as written, with no locale and no CSR boot query, so an endpoint mounted outside the API prefix can be opened; before, a full URL was taken by its path and given the locale. Whatever host a full URL names, and for a path that starts with `//`, preview stays on the app's dev server. `--csr` prints a note naming each path it opens as written instead of dropping the flag silently. The MCP endpoint answers only `POST`, so preview cannot check it, and the docs say so. A page `--changed` finds opens as a page even at a server route's path such as `/openapi.json`, under the same locale rule as a typed page. A screenshot's file name carries the page's query and a short hash of it, a path that is not plain lower-case words carries a hash of the path, and a long path or query is cut with a hash, so `/a/b` and `/a-b`, or `/_akan/studio?view=runtime` and `?view=signals`, no longer overwrite one another and a long query no longer fails the page. The `akan-debug` skill, `akan preview --help` and the `akan preview` reference state the same rule.
