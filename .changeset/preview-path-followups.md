`akan preview` opens `/openapi.json` and `/mcp` as written, as the server mounts them outside `/:lang`; before, they got the default locale and opened a 404 page. `/mcp` answers only `POST`, so its preview fails with 405, and the docs say preview cannot check it. A full URL (`http://localhost:<port>/oauth/token`) now opens its path and query with no locale and no CSR boot query, so an endpoint mounted outside the API prefix can be opened; before, a full URL was taken by its path and given the locale. Preview always stays on the app's dev server, for a path that starts with `//` too, and notes a full URL that names another server. `localhost`, `127.0.0.1` and `0.0.0.0` on the dev port, which `akan start` binds, are the dev server and get no note; `*.localhost`, which can name a sub-route host, still gets one. A full URL's scheme matches in any case (`HTTP://…`). `--csr` prints a note naming each path it opens without the CSR boot instead of dropping the flag silently. A page `--changed` finds opens as a page even at a server route's path such as `/openapi.json`, under the same locale rule as a typed page, and a trailing slash names the same page, so `/en` and `/en/` open once. A path that ends in a slash outside the framework's prefix routes is a page, as the server reads it: `/openapi.json/` or `/logo.png/` misses its exact route and the locale proxy redirects it. Two paths that would write one screenshot open once, such as `/board?akanMobileTarget=preview` and `/board` under `--csr`, or `?a=1&&b=2` and `?a=1&b=2`, and a note names the path that folded; the `--csr` note names only the rows that open. A screenshot's file name carries the page's query and a short hash of the query as sent, a path that is not plain lower-case words carries a hash of the path, and a long path or query is cut with a hash, so `/a/b` and `/a-b`, `?a=b+c` and `?a=b%20c`, or `/_akan/studio?view=runtime` and `?view=signals` no longer overwrite one another and a long query no longer fails the page. The `akan-debug` skill, `akan preview --help` and the `akan preview` reference state which paths open as written.
