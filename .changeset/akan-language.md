Editors can now jump from a name Akan.js derives to the key it comes from. `fetch.initMemoInPublic`, `st.do.setNameOnMemo` and `this.memoService.listByName` had no definition before, because TypeScript drops the declaration of a key a mapped type renames. A new package, `@akanjs/language`, indexes those names from source text, and an editor extension serves them. The extension (`pkgs/@akanjs/vscode`) is not on a marketplace yet; build it with `bun pkgs/@akanjs/vscode/build.ts --vsix`.

- **`@akanjs/language`** is an editor-neutral reverse index over a workspace's constant, document, service, signal and store files. It needs no type checker, and the host passes in its own `typescript`. For a derived name it answers definition and hover; for a source key it answers references, the keys to put a CodeLens on, and the edits of a rename. It covers slice names (`initMemoInPublic`, `slice.memoInPublic`, `memoListInPublic`), Filter queries (`listByName`), model CRUD and state (`getMemo`, `viewMemo`, `memoForm`), form setters across the `via(...)` chain (`setNameOnMemo` lands on `MemoInput.name`), store state setters, `subscribe`/`listen` endpoints, and module references (`this.memoService`, `srv.memo`, `sig.memo`). A name resolves within its own app and every lib, never another app. It ships as ES module and CommonJS with no runtime dependency.
- **The extension** adds those definitions and hovers next to TypeScript's, with a `Go to slice` link in the hover. A CodeLens on each slice key, Filter query key, constant field, store state key and pubsub or message endpoint shows its use count, plus the guards and `live` of a slice. Find References from a source key lists every derived use. F2 on a slice or Filter query key (or `Akan: Rename the slice or query key with its derived names`) renames the key, every name derived from it and its dictionary entry; a use that could also be another model's is left for TypeScript to report, and F2 elsewhere stays TypeScript's. In a trusted workspace it loads the workspace's own `@akanjs/language` when one is installed, so its rules match the framework version.
- **One copy of the name rules.** The templates behind the names apps call now live in `akanjs/common` (`sliceNames`, `queryNames`, `modelNames`, `databaseStateNames`, `formSetterNames`, `stateSetterName`, `endpointNames`, `moduleNames`). The runtime, devkit's scanners and scaffolds, and `@akanjs/language` all read them, and a type test fails when a mapped type and its table disagree. `databaseStateNames` and `formSetterNames` now live in `akanjs/common`; `akanjs/store` keeps them as deprecated aliases.
- devkit's write-placement and SSR checks read signals through the same reader, and its form-setter check now builds `set<Field>On<Model>` names forward from each module's constant instead of matching a pattern, so a slice setter such as `setPageOfProductOnSale` no longer reads as a field setter.
