Hardening for the ops channel, status and log routes, snapshots, the tunnel agent and dev-only surfaces.

- The ops channel counts only signed, verified calls toward its 30 a minute, so unsigned calls no longer spend that budget. Refused calls are limited separately, 10 a minute per caller address, and only the first 10 refusals a minute are logged one by one. The gateway and a solo server hand the ops channel, health, metrics and the log stream each caller's address, read through `TrustedProxy` as every other route reads it.
- An ops token's `typ` header must be absent, `JWT` or `akan-ops+jwt`; any other `typ` is refused before its `jti` is spent. Without `AKAN_OPS_INSTANCE`, the boot log says a token is good on every instance of the app and environment.
- The ops channel stays off, with an error at boot, when `AKAN_OPS_PUBLIC_KEY` is the same key as `AKAN_MACHINE_PUBLIC_KEY`. Give the ops channel a key of its own.
- `ops snapshot` outside local operation refuses to run when `AKAN_BACKUP_RECIPIENT` is unset, and so does a snapshot job started through the ops channel. `--allow-plaintext` or `AKAN_BACKUP_PLAINTEXT=1` writes it unencrypted as before, with a warning on stderr and in the job log.
- A snapshot is captured into a private `.capture-*` staging dir under the snapshot dir, named for its host and process, and renamed into place once complete. Its uncompressed database copy is 0600 and removed even when the capture fails. The next capture, and the ops channel when it starts, remove a staging dir whose process on this host is gone, including one from an earlier run under the same PID, and one another host left once nothing in it has changed for an hour (`SqliteSnapshot.staleAfterMs`). Snapshot files are 0600 and their dir 0700 by default; `AKAN_OPS_SNAPSHOT_FILE_MODE` (octal, e.g. `640`) sets another mode, and a value that is not a three- or four-digit octal mode keeps 600 with a warning.
- `ops restore` refuses a manifest whose file names point outside the manifest's own dir or name a role other than `main` or `solid`. Given `--identity` or `AKAN_BACKUP_IDENTITY_FILE`, it refuses a manifest that records no encryption unless `--allow-plaintext` is passed.
- Rotating log files are created 0600; `AKAN_LOG_FILE_MODE` (octal, e.g. `644`) sets another mode, and a value that is not a three- or four-digit octal mode keeps 600 with a warning. Files that already exist keep their mode. The log control socket is created under a 0177 umask, so it is never connectable by others before its chmod.
- `AKAN_STATUS_TOKEN` and `AKAN_LOG_STREAM_TOKEN` are compared as fixed-length digests, so the log stream route no longer compares lengths first. A token shorter than 32 characters still works, with a warning at boot that never prints it. Wrong bearers are limited to 10 a minute per caller address: once an address passes it, it gets the status alone and 401 for the rest of the minute, even with the right token.
- Open health detail and metrics, the devtools routes and an `x-akan-debug` header without the secret now need a local dev runtime: `AKAN_PUBLIC_ENV=local`, operation mode `local`, and either a `NODE_ENV` other than `production` or `akan start`. A built server under `AKAN_PUBLIC_ENV=local` keeps them closed. `AKAN_STATUS_TOKEN`, `AKAN_DEVTOOLS=true` and `AKAN_LOG_DEBUG_HEADER` still open each one explicitly.
- The `x-akan-debug` secret is compared as fixed-length digests, so a value of another length or with non-ASCII characters is refused instead of failing the request.
- A dev client report (`ClientReport`) prints its message, page, platform and target on one line, with line breaks shown as `\n` and C1 control characters removed.
- `TunnelAgent` takes a `wss://` gateway only, or `ws://` on loopback; `allowInsecureGateway: true` accepts any `ws://`. It opens tcp streams only to ports listed in `tcpPorts` (none by default), opens at most `maxSockets` data sockets (default 128, and never more than the gateway offers), and refuses an http or websocket stream whose path would leave the shared origin.
