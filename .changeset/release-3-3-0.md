Akan.js 3.3.0. Read **Upgrade notes** before deploying an app that runs 3.2.0: secret env values leave the build, every page enforces a script policy, a browser session moves to cookies with a one-hour token, the image runs as uid 1000, pages load their client runtime per route, and the surface 3.2.0 deprecated is removed.

**Highlights**

- **Pages load what they use.** A server-rendered page loads the stores, endpoint descriptors, constants and dictionary texts of the modules its client code names, the exports and object members it writes out (`Memo.Zone.View`, `Field.Text`), the icons it names, and no store, immer or agent library unless it uses one. In the sample apps the median route of `apps/akan` went from 535 KB to 304 KB of JS (brotli) and an empty page from 202 KB to 171 KB; the lightest route of a 236-route app went from 466 KB to 290 KB. `akan quality runtime` names the file and line that keep a route on the whole runtime.
- **Secrets stay out of the build.** `akan build` leaves the secret values of `env/env.server.<env>.ts` out of the server it builds. The server reads each from an environment variable and does not start while one is unset; `akan secret-env <app>` lists them and writes a Kubernetes Secret or a dotenv file.
- **Script policy.** Every HTML response enforces a `script-src` that names each script the framework writes, so the browser refuses any other inline script. `scriptHashes()` and `scriptNonce()` name a page's own, and `/_akan/csp-report` receives the browser's reports.
- **Sessions.** On `@libs/shared` a web session lives in HttpOnly cookies (`session.cookieOnly`), a browser's access token lasts one hour and renews itself, a revoked session's sockets close at once on every server, a user lists and signs out devices, admin password sign-in can be closed, and a verification code is kept as an HMAC.
- **Observability.** Request counts and latency for every endpoint and page with a Prometheus and OpenMetrics scrape; one request id through the gateway, the replica, the RSC worker, server `fetch` calls, websocket frames and queued jobs; `Server-Timing` and `db:` spans; OTLP/HTTP export of spans and logs; SQL statements counted by fingerprint with a slow-statement log, `/_akan/app/statements` and a local query-plan check; `option.setErrorReporter` and `option.setClientReport` for server, render, browser and native-shell errors; render admission control.
- **Agents.** `agentService.loop` loads tools as a run needs them (`search`, `listed`, `toolBudget`, `asked`), sends a history that only grows so a provider's prompt cache holds, and keeps Claude's thinking across tool rounds. A turn's context reaches the model as marked data outside the system prompt, and text someone else wrote (an `@` mention, an `untrusted` block, a `readState` answer) makes the next change ask first. `/mcp` gains `shelves`, `search` (`findTools`, `readTool`) and `structuredContent`. The in-page agent's `navigate` and `goBack` answer once the page they land on has loaded.
- **Workers and images.** `workers` in an app's or a lib's `akan.config.ts` builds, finds and supervises code that runs in a process of its own (`AppWorker.spawn`). The generated image runs as uid 1000 on a digest-pinned base under `tini`, builds for another architecture (`docker.crossBuild`), prunes in the install layer (`installRuns`), sets its own `env`, writes `variants` with their own env `profile`, and carries `bin`.
- **Navigation and native.** `usePendingNavigation()`, `Link`'s `pendingClassName`, `.loading(…, { atPress: true })` and `router.backOrReplace(href)`; every route level starts rendering at once (first flush 214 ms to 52 ms under three awaiting layouts). In a native app the page meets the keyboard as a native screen does on iOS and Android, a navbar can ride its page, a page can scroll under translucent chrome, a deep link opens a route with params over the screens `stackOn` names, Android's back closes a dialog first, and a dev build installs beside the store app as "<appName> Dev".
- **CLI.** `akan code` ships as `@akanjs/code` and asks before a shell command; `akan preview` opens pages signed in and `[param]` routes at declared examples; `akan start` boots the backend beside the first build; a whole-app lint runs about four times faster.

**Upgrade notes**

- **Secret env.** `akan build` no longer writes a secret value of `env/env.server.<env>.ts` into the server: a string under a secret-sounding key (password, secret, token, apiKey, privateKey, accessKey, webhook, aesKey, …) at any depth, or a URL with a password in it. The server reads each from a variable named after its place in the env file (`security.sso.google.clientSecret` from `SECURITY__SSO__GOOGLE__CLIENT_SECRET`; `security.jwtSecret` is `JWT_SECRET`, and `database.postgres.url`, `.password` and `.insightUrl` are `POSTGRES_URL`, `POSTGRES_PASSWORD` and `POSTGRES_INSIGHT_URL`) and exits with `secretEnvMissing`, naming each one, while one is unset. Before deploying an image built with 3.3.0, run `akan secret-env <app> --env <env>` and give the server those variables: `--format k8s --out <file>` writes a Secret to reference with `envFrom`, `--format dotenv` a file for `bun --env-file`. Rotate the values that images built before 3.3.0 still hold. A secret-named key whose value the env file computes or imports stops the build: write the string at the key, or `process.env.<NAME>`, which the build leaves as your own read. A key the rule does not recognise (`stripeKey`, a `salt`) stays in the build. `akan start`, `akan test`, `--profile` builds and desktop and mobile builds are unchanged. `SecretEnv.read` and `SecretEnv.json` take no fallback, and `SecretEnv.check()` throws instead of returning a report.
- **Script policy.** Every HTML response sends `script-src 'self' 'nonce-…' 'sha256-…' 'strict-dynamic' 'wasm-unsafe-eval'` with `report-uri /_akan/csp-report`. An inline script of your own needs `scriptHashes("sha256-…")` in its page's or layout's `.head()`, or `nonce={scriptNonce()}`; a `<script src>` written in JSX needs the nonce; an `onclick="…"` attribute or a `javascript:` URL moves into a handler. Deploy once with `AKAN_CONTENT_SECURITY_POLICY_REPORT_ONLY=on` and read the `[ScriptPolicy]` warnings to find them. The bootstrap script adds the client entry, so `load` and `DOMContentLoaded` can fire before any client code runs: check `document.readyState` before listening, and have a browser test wait for something the hydrated page does. Route state and Flight chunks are `<script type="application/json">` blocks, and the markup has no `<script type="module">` tag for the entry. A proxy or CDN that sets its own `Content-Security-Policy` must allow the app's scripts or leave the header to the app. A frame of your own that draws another server's HTML through `srcdoc` uses `McpAppHost.framePath`. `AKAN_CONTENT_SECURITY_POLICY_SCRIPT_SRC` replaces `'wasm-unsafe-eval'`, and `AKAN_CONTENT_SECURITY_POLICY` still replaces the whole policy.
- **Sessions (`@libs/shared`).** A browser's access token lives one hour. An app that mounts `Auth.User` or `Auth.Admin` renews it; one that mounts neither calls `refreshSession`, or its open tabs go anonymous an hour after sign-in until the next navigation. `session.cookieOnly` is on: a server-rendered page's sign-in, SSO and refresh answers carry `jwt: ""` and no `refreshToken`, and the page authenticates by cookie; hand the answer to `setAuth` and read the account with `getAccount()` / `getSelf()`. Set `session: { cookieOnly: false }` in `env/env.server.<env>.ts` to opt out, for a page that needs the token itself or is served as the client-rendered view on the server's own host. A native shell, a client-rendered app on another origin, a server and a test keep a seven-day token in the body, asked for with `x-akan-session-tokens: body`: an edge that answers CORS preflights from its own list adds that header. Your own endpoint answering with `makeAccessTokenResponse` passes the request, `makeAccessTokenResponse(token, { req })`. `RevokedSessions.accessTokenDays` is gone; `deniedSeconds` is how long a revoked session stays refused. A Redis ACL that lists channels allows `<key prefix>ws:revoke`. A verification code requested minutes before the deploy answers as wrong once.
- **Image and chart.** The generated image runs the server as oven/bun's `bun` user (uid 1000) under `tini`. A volume or bind mount an earlier image wrote is root's, so the server stops at boot with `directoryNotWritable`, which names the directory and the `chown -R 1000:1000` to run once; `--user 0:0` keeps a container on root, and a directory a `postRuns` step creates for the server needs the `chown` in that step. A `BlobStorage` subclass with its own `onInit` calls `super.onInit()`. The `infra/app` chart runs the pod as uid 1000 with no privilege escalation and every capability dropped, hands the `sqlite-data` claim to that user in a `volumePermissions` init container, holds the Ingress to `ingress.proxyBodySize: 128m`, and leaves CORS to the app (`ingress.cors.enabled: true` restores the annotations; `option.setCrossSite({ allowedOrigins })` covers `/api` only). An image built with 3.2 or earlier, or a custom image uid 1000 cannot read, needs `podSecurityContext: { runAsUser: 0, runAsGroup: 0, runAsNonRoot: false }`, `securityContext: { capabilities: null }` and `volumePermissions: { enabled: false }`. The Dockerfile opens with `# akan:dockerfile 1` and a marker before each section, so a tool that matched its first line or an instruction reads the markers.
- **Client runtime per route.** The first `akan build` or `akan start` writes `lib/usePage.ts` and `lib/__client/` beside the other generated files: add `apps/*/lib/usePage.ts`, `libs/*/lib/usePage.ts`, `apps/**/lib/__client` and `libs/**/lib/__client` to `.gitignore`. A page no longer loads a module that no client file of its route names. What that can break: a store, an endpoint or a model reached by a computed name outside the app's `client` barrel; an app store's additions read through the lib's `st`; a slice, init, view or edit object written by hand or deep-copied (`structuredClone`, `JSON.parse(JSON.stringify(…))`), which carries no reference to its model; top-level code in a store or part file the page does not name; and a dictionary key a client component builds from data, which shows as the key in the browser. `akan build <app>` then `akan quality runtime` names each file, line, reason and route. A route that renders a client file exporting `st` keeps the whole runtime. Client entries the same routes load are built as one file, so a file that does work when it loads now does it when any file of its group is first used. A registered model's `_`-prefixed member reads `undefined`, where it was `null`. `Dialog.LegacyModal` loads the first time it renders, so a test waits for its content. A test that replaces `akanjs/client` with `mock.module` passes `ShellState` through, and `msg.*`, `Copy` and a restored theme no longer call a store's own `showMessage` or `setTheme` action.
- **Removed surface.** `@akanjs/devkit` publishes only the subpaths its `exports` name, with no root alias and no `./*`: `applicationBuildRunner` is `@akanjs/devkit/app/applicationBuildRunner`, types come from `@akanjs/devkit`, and the `akan` command's internals have no public entry. `akanjs/common/*`, `akanjs/server/*`, `akanjs/ui/*`, `akanjs/webkit/*` and `akanjs/client/native/*` are gone as wildcards: import from the barrel or a named entry (`akanjs/client/native/<plugin>` and `akanjs/webkit/usePurchase` still resolve). `setErrorConstructor`, `HttpClientOptions.ErrorCls` and `FetchClient.build`'s `Err` option are deleted, as are `MAX_INT`, `isFilterModel`, `setFilterInfoByKey`, `getDefaultSchemaOptions`, `runWithTrace`, `traceDbQuery`, `isSitemapPath`, `useRscNavigation`, `getSearchParam`, `getBaseSearchParam`, `dictionaryContext`, `groupByOwner` and `ServiceRegistry`. `akan sync` rewrites the generated `lib/sig.ts` and `lib/useClient.ts`.
- **`akan code`.** A workspace that runs `akan code` adds `@akanjs/code` at its akan version (`bun add -d @akanjs/code@<version>`); code that imported `@akanjs/cli/code`, or the agent from `@akanjs/devkit/codeAgent`, imports it from `@akanjs/code`. On the `local` profile an interactive session asks before each shell command (`[y/n/a]`, where `a` stops asking about that command for the session); `--no-ask-commands` runs them unasked and `--no-ask` drops the network questions too. A program driving `akan code --rpc` answers an `approval` event per command.
- **Agents.** An `LlmAdaptor` that builds its own messages appends `LlmContext.of(request.context)` to the last user-role content and sends a `summary` message as a user turn (`LlmContext.summary`): `OpenaiDialect.systemPrompt` and `AnthropicLlm.systemPrompt` return the instructions alone. A store for `agentService.loop` messages keeps the new fields whole (`tainted`, `context`, `listed`, `lent`, `providerContent`, and `foundTools` on a summary), and a transcript view skips `context` messages as it skips `summary` ones. A loop whose messages carry `references` or an `untrusted` block is tainted: with no `approve`, each write is answered `writeAfterPageText`. A `stop_reason: "refusal"` throws `agent.error.llmDeclined`, where it read as an ordinary end. In the page, free text no longer rides in the turn's context (a long string, a search param no store declares, a row's title, a value published with `st.expose`, `st.useState` or `useAgentResource`, a zone's label): the model reads it with `readState` or `readScreen`, so a chat or zone that narrows `builtins` lists those two, and instructions that pointed at the context point at the tool. The first change after such a read, or after an `@` mention, asks first (`AgentConfirm.set({ afterScreenRead: false })` turns that off). A context-block field named `untrusted` now marks the block, and `findTools` is a reserved tool name when `search` is set.
- **Observability.** A trace id is 32 lower-case hex digits and always the server's own; a caller's `traceparent` or `x-request-id` is kept as `link`, which `akan logs --trace` matches, and `AKAN_TRACE_ADOPT=trusted-proxies` lets a proxy `AKAN_TRUSTED_PROXIES` names choose the id. `AKAN_BENCH_SKIP_REQUEST_ID` is gone. `db` and `dbMs` on a request line count SQL statements, not model calls, and a statement of 200 ms or more writes a `SlowStatement` warning (`AKAN_LOG_SLOW_STATEMENT_MS`). `SpanRecord` gains `id`, `parentId` and `startMs`. `/_akan/app/metrics` answers `Accept: text/plain` with Prometheus text (send `application/json` for the JSON) and gains `metricFamilies`; the `jsc…` fields come only under `AKAN_MEMORY_LOG=1`. A deployment whose environment already sets an `OTEL_EXPORTER_OTLP_*ENDPOINT` starts exporting spans: point it at a collector that takes OTLP/HTTP JSON, or set `OTEL_SDK_DISABLED=true`.
- **Dev routes.** Devtools, Studio and `/__rsc/manifest` answer only `localhost`, an IP address or a host the app names, and any other Host gets 403. A deployed server with `AKAN_DEVTOOLS=true` also needs `AKAN_LOG_DEBUG_HEADER` set to a secret of 32 characters or more. An endpoint registered under `/_akan/`, `/__rsc` or `/__csr` stops the server at start.
- **Route caches.** A page is keyed on the locale it resolved to, not on `Accept-Language`, and, when every level of its route declares what it reads with `.search()`, on its query sorted and without tracking parameters (`utm_*`, `gclid`, `fbclid` and the rest of `AKAN_ROUTE_CACHE_TRACKING_PARAMS`). Such a page renders with the sorted URL in every mode: read `Accept-Language` with `headers()`, declare a parameter a guard's redirect must pass on, or set `.config({ canonicalQuery: false })`.
- **Navigation.** In a CSR or native stack a push that changes only the query or hash rewrites its entry instead of stacking: a state opened that way closes with `router.backOrReplace(href)` or `router.replace`, since `router.back()` now leaves the page. A pushed page slides in at once, blank until its content lands unless it has a `.loading()`. A page body runs even when a layout body above it redirects, its output dropped: keep access control in `.guard()`. Under `AKAN_PUBLIC_RSC_PARTIAL_COMMIT=1` a layout is not rendered again when a param it does not declare moves.
- **Signals and data.** A bare value sent for an array argument over HTTP or WebSocket answers 400 `invalidArgument`: a hand-written body sends `["a"]` (MCP still lifts a lone value). In development and tests a call to a module the server did not mount answers `moduleNotMounted`, where a test met `base.error.unexpectedResponse`. A `new DataLoader(...)` without `copy` hands the callers of a repeated key one result object. Opening an optimized image's URL on its own downloads it.
- **Native.** An app that lists `external-view` opens no view until `native.desktop.externalView.allowOrigins` names the origins, with `evaluate: true` and `sendKey: true` for the calls it makes. An iOS dev build installs as `<appId>.debug`: register that App ID with its development profile, and send pushes to dev builds with the suffixed APNs topic. Under the new iOS and Android shells a page that lifted its own composer by the keyboard's height drops that lift.
- **CLI and tooling.** A failed `akan lint` exits 3, and a problem in an env file is reported by position alone. `ssh2` is an optional peer: a workspace that tunnels to a cluster environment runs `bun add -d ssh2` and sets `SSH_TUNNEL_PRIVATE_KEY_PATH` or `SSH_TUNNEL_PASSWORD`, since the built-in default credential is gone. `akan start` binds the port `PORT` names (`AKAN_DEV_PORT` still wins). `akan dbup` publishes Redis and Postgres on loopback in a new `local/docker-compose.yaml`; change the `ports` of an existing one by hand. The base Biome config turns `noUnnecessaryConditions` off (set it to `warn` in your own `biome.json` to keep it), a new workspace pins Biome 2.5.15, and `useArraySortCompare` warns on a `.sort()` with no compare function. The first `akan sync` after upgrading reorders the lib imports of generated files once. Code that builds an `AppConfigResult`, `LibConfigResult` or `DockerImageConfig` by hand adds `workers: {}`, `installRuns: []`, `crossBuild: false` and `env: {}`. Run `akan agent install` to pick up the shorter agent guide and skills.

**Features**

- **Client runtime.** `akan sync` writes one piece per module under `lib/__client/` and the page runtime `lib/usePage.ts`; a slice, init, view or edit object carries its model's reference (`_runtime`), so `Load`, `Model` and `Data` load that model alone; a route's dictionary is packed by module with the API descriptions in a file of their own (`Translator.ready(lang, key)`); an object's members and a file's exports are modules of their own, a workspace's own `Field` wrapper included; client entries the same routes load are one file; each `react-icons` icon ships once; a page runs one copy of `akanjs/client`; the form-field agent tools, `Dialog.LegacyModal` and the gesture library load on first use; `ShellState` in `akanjs/client` reads the path, theme and toasts without the store; client files under 1 KB are served compressed; a build writes `route-files.json`; and the development server loads what a production page loads.
- **Rendering and navigation.** `usePendingNavigation()` and `pendingClassName` on SSR and CSR alike; `.loading(…, { atPress: true })`; a query-only move keeps the page drawn instead of remounting it behind its `.loading()`; `router.backOrReplace(href)`, and `router.backOrFallback()` closes a tab the app opened; server route levels and CSR layers start their renders together, sharing a query two levels ask; a tab is drawn before it shows; a partial commit renders the page alone when only a param or query no layout declares moves; `.config({ overlay })`, `navbarMotion: "page"` and `stackOn`; `Dialog.Modal` plays a leave animation (`data-leaving`); `isNotFoundView()` and `isRedirectMove()`; the HTML cache answers `X-Akan-Cache: BYPASS` with `X-Akan-Cache-Reason` for a page it does not keep, holds a not-found URL out for 60 seconds at most and stores a page as the bytes it streamed; a page asks for its stylesheet before its chunks.
- **Server and data.** `workers`, `AppWorker.spawn` and `AppWorker.pathOf`; `option.setErrorReporter` and `option.setClientReport`; `akan_endpoint_*`, `akan_page_*`, `akan_route_cache_lookups_total`, `akan_db_statement*`, `akan_live_rooms`, `akan_room_replay_bytes` and `akan_pubsub_buffered_messages`; `AKAN_RSC_WORKER_MAX_CONCURRENCY` and `AKAN_RSC_WORKER_MAX_QUEUE`; `rscFirstRenderMemory` under `AKAN_MEMORY_LOG=1`; `WsCredentialRevocation.revoke`; `SignalSerializer.httpRoutesOf`; `configureSignalTest({ enableModules })`, and a signal test's fetch opens its socket on first use; a handler may return a constant with an `.optional()` field unset (`ServerReturnModel`); a loader sends at most 500 keys a query and asks for each key once; every page of a list is one SQL text and an insight one statement; under `akan start` the API answers while the first build runs.
- **Agent and MCP.** `agentService.loop` options `search`, `listed`, `toolBudget` and a toolkit's `instructions` and `asked`; a compaction closes toolkits the kept messages do not use, and `compact.at` counts tools, instructions and context; `AnthropicLlm.of(option)` with `body` and `betas`, thinking replayed as `providerContent`, and a page's lent tools kept in place (`lent`); a failed turn is logged once (`LlmOverflow.failed`); `LlmContext`; `AgentNavigate.set({ description, settle })`, `ScreenSettle.loaded()` and `isLoading()`; a write's change report marks what it leaves out `withheld`; `option.setMcp({ shelves, search, structuredContent })`.
- **Image and deploy.** `docker.crossBuild`, `installRuns`, `env`, `variants` with `profile`, `baseSetup: false` and `image` per architecture; a generated `.dockerignore`; `@akanjs/devkit/akanConfig` exports the Dockerfile generator (`dockerfileOf`, `dockerfileLayoutOf`); `bin` entries are fetched for `linux-x64` and `linux-arm64` into the image; a lib takes `workers` and a `script/` folder; `routes[].syncPageLibs` chooses the lib pages a `basePath` mounts.
- **Native.** Page-level keyboard avoidance (`KeyboardRide`, `data-akan-keyboard-ride`, `data-akan-keyboard-overlay`, `nativeKeyboardEasing()`); `native.ios.hideFormAccessoryBar`; `ios.debugAppIdSuffix` and `debugAppNameSuffix`; a plugin manifest `scope` with `required: true`; the ML Kit document scanner in the pinned Maven lock; Android's back closes the newest open surface, with `useEscapeKey(active, onEscape, { back: false })` to keep it for the page; a native page reports its errors when `setClientReport` is on.
- **`@libs/shared`.** `setAdminSsoPolicy({ canPasswordSignin })`; sign-in sessions with a device kind, user agent, network prefix and `lastUsedAt`, listed and revoked by their user; `setSecuritySignalHook` (`signinLocked`, `refreshReuse`, `newDeviceSignin`); `option.setSessionRefresh` renews an expired token before a page renders; `SignCode`.
- **CLI.** `akan secret-env`; `akan code --no-ask` and `/allowed`; `akan preview` with `preview.signIn`, `preview.examples`, `--as`, `--anonymous` and `--wait-for`; `akan start` restarts only the backend on a signal or dictionary save, keeps its build caches between runs and prints where the start's time went; `akan test`, `akan preview` and `akan verify` take their list as separate words; `akan verify` lists an added comment once and writes its build check to `dist/verify/<app>`; `akan build` prints one plain line per phase off a terminal, fails when a client file imports server code or the pages bundle would import `react-dom/server`, and keeps every base path's CSS class scan cached; `akan sync` seeds a worktree's missing env file from the main checkout, removes a module folder left with only its `index.ts`, and settles in one run with libs in a fixed order; `akan update` waits until the registry serves every package of a release; `create-ui` writes a Zone or a Util, for a service module too; a workflow plan names the flag of a missing input; `akan lint-all` runs Biome once; `akan --version` loads no command module; a new workspace lists no `tailwindcss`.
- **Agent guide.** The generated `AGENTS.md` gains a Read First section and is about 9% smaller, the path rules a fifth shorter, and the skills no longer repeat a rule the agent already loaded. The published packages leave `CHANGELOG.md`, `ARCHITECTURE.md` and `CONTRIBUTING.md` in the repository.

**Fixes**

- A page no longer shows a broken character where React's 4 KB output buffer ended inside a multi-byte character (Korean, Japanese, an emoji).
- A built `main.js` sets its build's env before React loads: `bun main.js` on a host with no `NODE_ENV` loaded React's development build and failed every server render.
- A query or mutation called with an empty path argument fails with `base.error.requiredArgument` before it is sent, and an API path that names no endpoint answers a JSON 404 `routeNotFound` instead of the page.
- A WebSocket frame whose `key` names a member of `Object.prototype` answers 404, one whose `data` is not an array 400 `invalidMessage`, and an MCP `POST` whose body is `null` 400, where each answered 500.
- A publish to a pubsub room whose `String` argument is `""` reaches its subscribers, and an own `__proto__` key in a room argument is part of the room id.
- A `load<Model>Many` with more ids than one statement takes loads, a batch function that throws rejects its callers, and on SQLite a read by a list of ids goes through the primary key (6 ms to 0.03 ms at 20,000 rows).
- The SQLite cache sweeps expired entries in batches through an index, and a `get` that saw an expired entry no longer removes the value another process just wrote.
- A Tailwind class marked important (`h-0!`, `md:!h-0`) compiles with `!important`, and a stylesheet that uses no Tailwind skips its compiler.
- A package's module worker (Excalidraw's font subsetting) loads in a production build.
- `Input` drops its invalid message when the value is emptied.
- `st.do.<action>` stays the same function when a later store root repeats its store, and in development `st.use`, `st.do` and `st.slice` throw on a key no loaded store declares.
- In a CSR app a redirect from a page out of sight no longer leaves a blank page, and a fetch-handle field nobody read no longer rejects unhandled.
- On iOS the camera and the in-app browser present `.overFullScreen`, so the page under them is not suspended and reloaded, and a native `indexPath` with a query opens on that page.
- A precompressed asset is streamed from disk (about a quarter of the CPU per request), a render sends the client manifest to the RSC worker once (a burst of cached pages from about 38 ms to 7 ms at the median), and a server's bundles carry less code it never runs.
- `/_akan/image` responses carry `nosniff`, a sandboxing `Content-Security-Policy` and `Content-Disposition: attachment`.
- `create-module` scaffolds the `inPublic` slice with a `.desc()`, and `akan build` and `akan verify` print no `File Create:` line per output file.
