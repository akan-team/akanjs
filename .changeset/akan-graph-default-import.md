The Akan Graph reads a lib module that imports a package's default export and exports it by name (`import Stripe from "stripe-sdk"; export { Stripe }`, or `export { PayClient as Pay }`) as that package's re-export, the same as `export { default as Stripe } from "stripe-sdk"`. Along the plug's import chain, with or without the generated barrel, the plug is `adaptor:stripe-sdk:Stripe` (or `adaptor:pay-sdk:Pay`), where it was the unlocated `adaptor:<lib>:<Name>`. As with that named re-export, a lib's own adaptor of the same name, where one is declared, still takes the plug before the package does. A namespace import (`import * as sdk from "mollie-sdk"; export { sdk }`) and a default import of a relative or lib module are still the module's own export, and guards are unchanged.

A package's default that reaches the plug only as `default`, through `import Stripe from "stripe-sdk"; export { Stripe as default }` or `export { default } from "stripe-sdk"` behind `export { default as Stripe } from "./stripeClient"`, is named after the plugged name: `adaptor:stripe-sdk:Stripe`, where the first was the unlocated `adaptor:<lib>:Stripe` and the second `adaptor:stripe-sdk:default`.

`export * as Stripe from "./legacy"` is now the module's own binding of `Stripe`, as ES modules make it, so an `export *` beside it, in the same module or a sibling the barrel also stars, no longer supplies the name (#582). A plug of `Stripe` through it is the unlocated `adaptor:<lib>:Stripe`, where it was the adaptor that `export *` reached. `export type * as Stripe from …` binds no value and changes nothing. `export{Stripe}`, written without a space, is the module's own export as `export { Stripe }` is, so `import * as Stripe from "stripe-sdk"; export{Stripe}` beside an `export *` also leaves the plug unlocated where it took the starred adaptor.
