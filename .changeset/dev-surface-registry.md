Every dev route (`/_akan/devtools`, `/_akan/constant`, `/_akan/signal`, `/_akan/dictionary`, `/_akan/deps`, `/_akan/studio`, `/_akan/hmr`, `/_akan/ssr-dev`, `/_akan/csr-dev` and `/__rsc/manifest`) is listed once, in `akanjs/server/routing/devSurfaces`, and takes its gate, its Host check and its `akan dev --share` rule from that entry. A dev route answers only localhost, an IP address or a host the app names, on a deployed server too. A share reads the same list, so it now also refuses `/__rsc/manifest`; it still serves `/_akan/ssr-dev` and `/_akan/csr-dev`, which a shared dev page loads its modules from.

The framework keeps `/_akan/`, `/__rsc` and `/__csr` for its own routes: a server now refuses at start an endpoint, a framework route or a web route under them that is neither mounted as a dev route nor on the list of production routes next to the registry, and the error names the path. A dev server starts its on-demand CSR build only for a Host a dev route answers. A share refuses `/__csr` and drops `csr=true` from a page's query, so a shared page renders on the server instead of starting that build.

Outside a local runtime, `AKAN_DEVTOOLS=true` opens devtools only to a caller that presents the `AKAN_LOG_DEBUG_HEADER` secret, which must have at least 32 characters: a script sends it as `x-akan-debug`, and a browser posts it once to the form devtools shows, which unlocks that browser for 15 minutes, for that app and environment only, with an HttpOnly, Secure, SameSite=Strict cookie on the devtools paths; ten wrong secrets in a minute from one address get 429 until the minute is over. With no secret set, or a shorter one, devtools stays closed and the server log says which. Request logging through `x-akan-debug` takes the secret as before, whatever its length.

**Upgrading.** Open devtools, Studio and `/__rsc/manifest` through `localhost`, an IP address, `<app>-<env>.<serveDomain>`, a domain in the app's routes or a name in `AKAN_ALLOWED_HOSTS`; any other Host now gets 403, even on a server that answers every Host for the rest of the app. A deployed server with `AKAN_DEVTOOLS=true` also needs `AKAN_LOG_DEBUG_HEADER` set to a random secret of at least 32 characters (new: a shorter one keeps devtools closed there, and still works for request logging): send it as `x-akan-debug` from scripts, or unlock a browser at the form on any devtools page over HTTPS or `localhost` (for example through a port-forward). A local `akan start` or dev server needs nothing. An endpoint registered under `/_akan/`, `/__rsc` or `/__csr` (with `globalPrefix: false`) now stops the server at start: move it to another path.
