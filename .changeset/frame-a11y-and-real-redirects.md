A frame slot whose inset is 0 at a width is hidden from the keyboard and screen readers as well as clipped, so a phone-only bar needs no `md:hidden`. A redirect a page raises after the RSC stream started is a real 3xx when the host still holds the response (a `.config({ ssr: "block" })` route, a crawler, or one raised before the shell was ready). `Layout.BottomTab` renders a `<nav>` named by `label`, and a tab's `content` / `activeContent` draw it from a server component. `router.back()` reports the page it landed on rather than `document.referrer`, and a CSR bundle's store holds the URL's query before its first page renders. The cssRule safe-area note now says the web reads `env()` only where the route chain declares `safeArea`.
