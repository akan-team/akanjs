# doc Service Abstract

Serves the Akan.js documentation corpus to agents, so an agent working in an Akan workspace can read the framework's
own docs through MCP instead of guessing at its APIs.

## Rules

- The corpus is read, never written. Pages come from `public/llms/pages`, generated by `script/generateLlms.ts` from
  the `page/(docs)` routes; changing what an agent sees means changing a docs page, never this module.
- Every endpoint is `[Public]`, deliberately. The same markdown is already served anonymously at `/llms/pages`, so a
  guard would protect nothing and would make the tools unusable to the agents they exist for.
- A missing corpus yields an empty catalogue and one warning, not a boot failure — an app deployed without its
  generated docs should still serve the site.
- Search requires every word to match, so adding a word narrows the result. Title hits outrank body mentions
  because a page *named* for the query is almost always the one wanted.
